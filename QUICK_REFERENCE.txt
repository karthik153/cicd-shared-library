🚀 QUICK START (5 seconds)
─────────────────────────────────────────────────────────────────────────────────

Windows (PowerShell):
  .\build-ace-local.ps1 -BarFilePath "C:\Users\YourUser\Documents\myapp.bar"

Linux/Mac (Bash):
  ./build-ace-local.sh -b /home/user/myapp.bar


📝 COMMON COMMANDS
─────────────────────────────────────────────────────────────────────────────────

Build and Run (Default - Automatic)
  PowerShell: .\build-ace-local.ps1 -BarFilePath "C:\path\to\app.bar"
  Bash:       ./build-ace-local.sh -b /path/to/app.bar

Build Only (No Auto-Run)
  PowerShell: .\build-ace-local.ps1 -BarFilePath "C:\path\to\app.bar" -RunContainer $false
  Bash:       ./build-ace-local.sh -b /path/to/app.bar -r false

Test Environment (Different Port Range)
  PowerShell: .\build-ace-local.ps1 -BarFilePath "C:\path\to\app.bar" -Environment test
  Bash:       ./build-ace-local.sh -b /path/to/app.bar -e test

Custom Container Name
  PowerShell: .\build-ace-local.ps1 -BarFilePath "C:\path\to\app.bar" -ContainerName myapp-v1
  Bash:       ./build-ace-local.sh -b /path/to/app.bar -c myapp-v1

📊 CONTAINER MANAGEMENT
─────────────────────────────────────────────────────────────────────────────────

List All Local Build Containers:
  docker ps --filter "label=local_build=true"

Find Container by Environment:
  docker ps --filter "label=environment=dev"

Find Container by App Name:
  docker ps --filter "label=app=myapp"


🔧 TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────────

❌ "BAR file not found"
   → Use full path (C:\Users\...\file.bar, not relative paths)
   → Check file exists: dir C:\path\to\file.bar

❌ "Port already in use"
   → Use different environment: -Environment test
   → Stop conflicting container: docker stop container-name

❌ Container won't start
   → Check logs: docker logs ace-myapp-xxxxx
   → Verify Docker is running: docker ps
   → Check Dockerfile exists: dir Dockerfile.ace-generic

❌ "Dockerfile.ace-generic not found"
   → Script must be in same directory as Dockerfile
   → Current location: cicd-shared-library/

💡 TIPS
─────────────────────────────────────────────────────────────────────────────────

Tip 1: Run Multiple Versions Simultaneously
  • Dev:     .\build-ace-local.ps1 -BarFilePath app.bar -Environment dev
  • Test:    .\build-ace-local.ps1 -BarFilePath app.bar -Environment test
  Both run at same time on different ports!

Tip 2: Custom Container Naming
  Give meaningful names for production-like testing:
  -ContainerName my-payment-service-v2 (PowerShell)
  -c my-payment-service-v2 (Bash)

Tip 3: Keep Terminal Open for Logs
  Start script, keep terminal open to see live logs of container startup

Tip 4: Use Absolute Paths
  Always use full paths (C:\... on Windows, /home/... on Linux)
  Don't use relative paths like .\file.bar

Tip 5: Check Port Availability
  Windows: netstat -ano | findstr :7800
  Linux:   lsof -i :7800
